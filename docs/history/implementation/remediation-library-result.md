# 扫描队列与媒体键整改结果

## 改动

- `LibraryViewModel` 现在按序接收目录扫描，将规范化并解析符号链接后的重复目录合并到同一次扫描，并向每个提交者分别回传完成或失败。界面状态包含当前目录、等待数量、完成/失败数；单个目录失败后仍会启动后续任务。
- `SettingsViewModel` 将“已提交”与“扫描结束”分开反馈，等待实际接收层回调，汇总失败和不可用目录。重复的全量扫描提交由媒体库队列去重，过期批次回调不会覆盖当前状态。
- 媒体键解析改为读取完整 16 位键码及 flags 中的按下/释放状态。按下只触发一次，释放清除按住状态，未知事件忽略。应用生产初始化选择 `MPRemoteCommandCenter` 通道，事件监视器不会重复处理同一按键。
- 新增真实接收链回归用例，覆盖两个临时目录均入库、首个目录失败后第二个继续、活动与排队目录去重及回调、设置反馈批次隔离；新增媒体键实际接收器用例，覆盖播放/下一首/上一首、按下释放去重、未知事件与单生产通道。
