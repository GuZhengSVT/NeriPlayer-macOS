# 播放栏与首页 / 搜索 / 媒体库重做

日期：2026-10-02。范围依据本轮用户请求；下载管理页面未修改。对照 Android 本地工程的 `HomeScreen`、`HomeViewModel`、`ExploreScreen`、`LibraryScreen`。

## 实现范围

| 页面 / 功能 | 本轮行为 |
|---|---|
| 播放栏 | 顶部固定进度轨道、可点击 / 拖动 seek、已播与总时长；无歌曲保留空轨，换歌未知时长保留加载状态。歌曲信息、歌词、播放与辅助工具分区，布局高度固定。 |
| 播放与辅助工具 | 上一首 / 播放暂停 / 下一首、顺序 / 列表循环 / 单曲循环 / 随机、播完当前曲暂停、收藏 / 加入歌单 / 新建歌单、歌词、桌面悬浮歌词、应用音量与队列。 |
| 窗口适配 | 依据播放栏实际宽度渐进收起辅助按钮；主要播放按钮与队列始终可见。更多菜单可访问收起的工具和音频规格。 |
| 音频规格 | 从 libmpv 当前音源读编码、实际比特率、采样率与声道，缺字段时省略。显示规格不等同于新增平台音质选择。 |
| 队列 | 打开当前播放队列浮层，标记 / 定位当前项，可点播和移除；不跳转媒体库。 |
| 首页 | 私人雷达、每日推荐与私人 FM；飙升 / 新歌 / 热歌榜；推荐 / 每日 / 精品 / 热门 / ACG 歌单；雷达歌单与 YouTube Music 首页 shelf。登录专属分区按状态显隐。歌曲区使用横向三行列表，歌单用自适应卡片。 |
| 首页加载 | 分区独立请求与缓存、失败保留上次内容、按账号隔离；点击歌曲按分区整组入队，点击歌单打开对应媒体库详情。每日推荐按上海日期失效。 |
| 搜索 | 第二个导航项由“探索”改为“搜索”。平台歌曲、网易云歌单 / 专辑 / 歌手、YouTube 创作者、全部平台歌曲搜索；结果分页、搜索历史、链接识别及 Bilibili 分 P。 |
| 媒体库 | 第三个页面分“本地、收藏、网易云、Bilibili、YouTube”五栏。本地仅显示文件曲目；收藏包括歌曲与本机收藏的歌单 / 专辑。平台歌单移入这里，各平台状态分别持有，共用缓存。 |
| Bilibili 封面 | 优先使用与 Android 一致的 `/x/v3/fav/folder/info` 元信息，必要时取首个视频封面；封面错误记录到日志，列表异步回流时保留已补封面。 |
| 设置 | 内部导航改为稳定双栏，禁用分类转场；滑杆数值在 setter 吸附，去掉 AppKit 密集刻度；账号单独观察与加载。原因与证据见设置性能记录。 |

## 明确边界

- 页面结构与已实现内容按 Android 调整，尚未声称 Android 全部功能等价。独立正在播放页、队列拖动排序 / 保存队列、平台音质选档、Bilibili 合集、完整 YouTube 创作者页和全部设置项仍是后续范围。
- 搜索历史与歌单 / 专辑收藏当前存本机 UserDefaults；后者尚未接入跨端同步。歌曲收藏与本地歌单沿用现有数据库和同步模型。
- 链接识别支持直接平台链接 / BV / av；短链跳转与自由文本分享链接不在本轮识别契约中。
- 真实在线推荐由账号、地区和网络决定。错误 / 未登录状态必须明确，不用静态示例填补。YTM 真账号推荐和私有歌单需要单独记录验证情况。
- 设置采样证明布局 / 刻度路径成本显著；嵌套导航是待对照修复验证的布局因素，不把所有卡顿归因于它。
