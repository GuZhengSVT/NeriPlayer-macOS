## Android 逻辑对照

实现对照 Android checkout `12351888e64178b145bc612b7d8e40efa7497d95` 的：

- `DownloadOperationState` 的核心阶段和取消/恢复边界；
- `AudioDownloadTransferPolicy` 的强 ETag 续传、Content-Range 校验、资源 URL 易变参数过滤、重试分类和上限；
- `AudioHlsSegmentSupport` / `AudioHlsResumeStore` 的最终 HLS 清单限制、分段复制、ID3 跳过、playlist fingerprint 和 durable prefix hash；
- `AudioDownloadManagerAttempt` 的 core commit 与 assets/metadata 收尾分离。

Android 的 Room、WorkManager、通知、文档树和移动网络策略改为 macOS 等价物：Swift actor + JSON journal、应用生命周期调度、SwiftUI 下载页、Application Support/Library Caches、`NWPathMonitor`/URLSession。没有把 Android 专属存储 API 伪装成 macOS 能力。
