## Android 对照

直接参考 Android checkout `12351888e64178b145bc612b7d8e40efa7497d95` 的 SyncDataModels、SyncDataSerializer、SyncPlaylistSongMergePolicy、SyncPlaylistDeletionPolicy、SyncSongMetadataMergePolicy、SyncPlaybackStatsMergePolicy、GitHubRepositorySyncTransport、WebDavSyncManager 和 SongIdentity/BiliSongResolver。原字段、时间和冲突原则与 macOS 适配边界见 [移植笔记](../m7-sync-notes.md)。
