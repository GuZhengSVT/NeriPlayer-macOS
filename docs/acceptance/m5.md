| 平台 | 搜索 | 音源解析与解码 |
|---|---|---|
| 网易云 | 返回 30 条 | song ID `33894312`，完整授权检查后的 URL，由真实 libmpv 加载，进度超过 0.3 秒，时长约 267.23 秒 |
| Bilibili | 返回 19 条 | 从真实搜索结果解析音轨；libmpv 加载并推进，最后一轮样本时长约 211.37 秒 |

解码探针使用 `ao=null` 保留解码和播放时钟但不出声；以上不是硬件听感、播放整首或长时连续稳定性证据。

YTM 最初缺少 signature timestamp 和 JSC 库命名空间，随后修复。CDN 对 URLSession 与 FFmpeg 请求有差异：前者 206、后者 403；采用本机 URLSession Range 转发后解码通过。没有 PoToken、会员/地区权限绕过，也不持久化音频文件。

## 扫码确认回归修复（2026-10-01）

用户真实扫码在 scanned/确认阶段被拒绝。对照 Android 发现旧版二维码路径、缺失 chainId/网页登录头，以及未处理 x-refresh-token 的兼容缺陷。已改为 scanlogin 链、临时 QR Cookie 和 803 后账号校验；校验通过才写 Keychain，失败时清除界面中的等待确认状态并显示 API code。621 全量用例通过（6 个可选用例跳过），新增 3 个确认链回归；真实 QR 生成及 waiting 探针通过。尚未用用户手机复验 authorized。该轮尚未接入官方 ydDeviceToken，后续用户确认仍返回 8821，见下述补充修复。

### 8821 设备上下文补充

用户反馈确认请求返回 8821 后，发现轮询中的 ydDeviceToken 仍为空，设备 ID 仍为 unknown 回退。已接入非持久化 WKWebView 加载网易云官网，调用官网 createNEFingerprint SDK 获取真实 token，并采集同一会话 sDeviceId 与 Cookie；二维码 chainId 和轮询使用这份上下文。获取失败或空 token 不再允许生成二维码，支持超时和取消，界面显示准备登录状态。不伪造设备凭据，也不绕过平台验证。

本轮全量 622 用例通过，6 个可选用例跳过；lint 仅历史数据库文件长度告警。真实官网 SDK 获取非空 token/设备 ID 并进入 waiting 的探针通过，耗时约 2.4 秒。最终手机确认后的 803 授权仍未由用户复验，不将 waiting 通过当作完整登录成功。
