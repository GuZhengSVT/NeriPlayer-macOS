# M4 歌词系统验收

日期：2026-09-30

## 已实现

- T1：Enhanced LRC、YRC、TTML、Lyricify SYL、KRC、翻译/音译和文本导出模型。
- T2：同名 `.ttml`/`.yrc`/`.lrc`/`.txt` sidecar；显式网易云 song ID 的 URLSession provider；YRC 优先、LRC 回退、翻译/音译按时间合并；本地错误与无 ID 不会意外联网。
- T3：`LyricsTimeline` 使用预计算区间树，支持长行重叠、闭区间边界、负/正偏移、反向跳转、异常时间值饱和处理。
- T4：SwiftUI 歌词窗口，逐行滚动高亮、点击跳转、字号/模糊/翻译/音译设置、边缘渐隐；滚轮或拖动后暂停自动跟随。
- T5：AppKit 原生文本布局按音节裁切 accent，高亮支持中文、英文长句自动换行、伴奏行和音译。
- T6：可选 1–6 行的白底黑字/首行绿色 1080px PNG 卡片，支持预览、保存桌面和复制剪贴板。
