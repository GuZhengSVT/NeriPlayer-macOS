# 首页、底部播放器与分类设置记录

日期：2026-10-01。本次基于现有 M7–M9 实现补充桌面界面，参考本地 Android 工程的首页和 SettingsPage 分类结构。

## 当前实现

| 功能 | 行为与入口 |
|---|---|
| 首页 | 替换原占位页。显示当前播放队列的继续播放卡片、探索/媒体库/下载快捷入口、当前在线平台最多六首推荐、媒体库曲目/专辑/歌单数量。空队列显示开始播放提示。 |
| 底部播放器 | 跨首页/探索/媒体库/下载/设置常驻，空队列隐藏。显示标题、歌手与在线封面，上一首、播放/暂停、下一首、只读进度、歌词按钮和媒体库入口。订阅现有 PlaybackStateStore 快照。 |
| 在线收藏封面 | 当 OnlineCollection.artworkURL 为 nil 时，调用现有 songs(in:) 接口，使用返回数组第一项的 artworkURL。已有封面保持不变。详情加载后也会回填当前详情与同 ID 列表条目。 |
| 分类设置 | 使用 NavigationSplitView，将账号、通用、外观与个性化、播放与音质、歌词、网络与下载、存储与媒体库、备份与同步、一起听、关于分别展示在独立详情页。 |
| 已有设置接入 | 启动续播/启动音量、主题/强调色、账号登录面板、音效输出、媒体库目录、备份同步、一起听和诊断窗口沿用原有状态与写入接口。 |

## 封面兜底边界

网易云歌单和 Bilibili 收藏夹共用视图模型的兜底流程。该流程只更新应用内集合模型，不修改平台账号的远程封面，也不新增数据库持久化。刷新后重新根据平台数据计算。集合为空、第一项没有封面或详情请求失败时保留占位图。

当前只识别 nil 封面；非 nil 但无效或图片下载失败的 URL 不会触发首项兜底。封面加载仍使用现有 AsyncImage。兜底复用完整详情接口，较大歌单或大量无封面收藏夹可能增加网络请求与等待时间。

## 设置与界面边界

分类结构已接入，但不等同于 Android 全部设置已移植。“歌词”和“网络与下载”分类目前主要提供现有行为说明，歌词参数仍在歌词窗口调整；“打开歌词设置”按钮当前尚未连接实际动作。独立平台音质选择、网络策略和下载偏好没有在本次新增。

首页复用 OnlineViewModel 已加载的推荐，不单独触发首次推荐加载。底部进度是只读显示，没有拖动跳转、音量或模式选择；列表按钮目前切换到媒体库，不展示独立队列弹窗。本地曲目在首页与底部栏使用默认图标，尚未读取媒体库的本地封面。
