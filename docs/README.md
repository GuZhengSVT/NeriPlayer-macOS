# NeriPlayer macOS 文档归档索引

本目录记录的是这个 Swift/macOS 移植项目的历史规划、实现过程、验收记录和后续调研，不代表项目目前仍在维护，也不构成对当前版本持续支持或持续验证的承诺。

作者 cwuom 的 [NeriPlayer-Desktop 官方桌面端](https://github.com/cwuom/NeriPlayer-Desktop) 已提供 macOS 支持。这个 Swift 项目完成了独立原生移植实验的历史使命，因此归档并停止维护。项目最终支持目标定为 macOS 27；macOS 13 不再属于支持范围。

- [2026-10-14 核心整改记录](remediation-2026-10-14.md)：归档前的独立检查、整改事项及当时记录的实现和验证范围。各条目反映当时工作记录；其中自动化检查、人工操作和真实设备检查的证据范围不同。
- [2026-10-15 上游更新与桌面移植调研](upstream-review-2026-10-15.md)：归档前对上游变更、官方桌面端和同步协议差异的调查。特别记录了本 Swift 工程尚未适配 Android V4 同步协议；V4 manifest、ZSTD 分块和对象图均未实现，因此旧同步格式的兼容实现不能视为 V4 互通支持。
